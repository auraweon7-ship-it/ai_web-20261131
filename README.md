# 교양중국어 강의 사이트

고려대학교 중어중문학과 「교양중국어」 강의를 소개하고 수업 활동을 돕는 한 페이지 웹사이트입니다. 서버와 빌드 과정 없이 `index.html` 하나로 동작합니다.

**사이트 주소:** https://auraweon7-ship-it.github.io/ai_web-20261131/

> **체험 모드 안내:** 서버가 없어 회원가입, 출석, 과제, 투표 기록은 입력한 사람의 브라우저에만 저장되며 교수자에게 전달되지 않습니다. 실제 운영에는 서버 연결이 필요합니다. 지금은 소개와 시연 용도로 사용해 주세요.

## 주요 기능

| 기능 | 설명 |
|---|---|
| 강의 안내 | 강의 소개, 15주 학습 계획, 수업 달력, 수강 안내, FAQ, 교수자 소개 |
| 공지사항 | 3개씩 페이지로 표시, 맨 위 고정, 접속 시 팝업 표시 |
| 주제 투표 | 가장 먼저 배우고 싶은 주제 투표 (같은 브라우저의 탭끼리만 공유) |
| 회원가입·로그인 | ID와 PW로 가입하고 헤더의 로그인 버튼으로 로그인 |
| 출석·과제 | 출석 체크와 과제 제출 기록 (파일은 업로드되지 않고 이름, 크기, 시각만 기록) |
| 주차별 학습 자료 | 관리자 첨부 파일을 참고해 AI로 만든 강의 노트, 과제, 중국어 문장 50개(병음, 번역, 듣기), 이미지, 온라인 퀴즈, 문화 슬라이드와 유튜브 영상·노래 |
| 실시간 퀴즈 | QR 코드로 입장해 여러 기기가 함께 참여, 결과 CSV 저장 |
| 관리자 화면 | 내용 편집, 공지 관리, 가입·출석·과제 내역 CSV, AI 키, 설정 파일 관리 |

## 실시간 퀴즈

이 사이트에서 유일하게 여러 기기가 실제로 연결되는 기능입니다. 교수자 브라우저가 진행을 맡고 학생 기기와 WebRTC로 직접 통신합니다.

- https 주소에서 열어야 휴대폰이 QR 주소로 접속할 수 있습니다.
- 학교 와이파이 등 일부 망은 WebRTC를 막을 수 있으므로 수업 전에 실제 휴대폰으로 시험해 주세요.
- 진행 중에 교수자 탭을 닫으면 결과가 사라집니다. 끝나면 바로 CSV를 저장해 주세요.
- 본인 확인 기능이 없어 성적 반영용으로는 적합하지 않습니다.

## AI 문제 출제

관리자 화면의 **AI 키** 탭에 Anthropic(Claude) 또는 BAZE API 키를 등록하면 퀴즈 문제를 AI로 출제할 수 있습니다. 두 키를 모두 등록하면 Anthropic을 먼저 쓰고, 실패하면 BAZE로 다시 시도합니다. 키가 없으면 프롬프트를 복사해 다른 AI에 붙여 넣고 받은 JSON을 불러올 수 있습니다. AI가 낸 문제에는 오류가 있을 수 있으니 정답을 검토해 주세요.

API 키는 등록한 브라우저에만 암호화 없이 저장되며 저장소와 배포 파일에는 들어가지 않습니다. 공용 컴퓨터에는 등록하지 마세요.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 사이트 전체 (화면, 스타일, 스크립트, 설정) |
| `professor.jpg` | 교수자 사진 |
| `week-content.json` | 주차별 학습 자료 (관리자가 내려받아 추가, 없으면 표시 안 함) |
| `README.md` | 이 문서 |

사이트 내용은 `index.html`의 `window.SITE_CONFIG`에 모여 있습니다. 화면 왼쪽 위의 빨간 글씨가 현재 버전이며, 수정할 때마다 `version` 값을 올립니다.

## 실행과 배포

**내 컴퓨터에서 보기:** `index.html`을 더블클릭해 브라우저에서 엽니다.

**GitHub Pages:** 이 저장소의 `main` 브랜치 루트(`/`)에서 배포됩니다. `main`에 올리면 잠시 뒤 사이트에 반영됩니다.

**Vercel 등 다른 호스팅:** 빌드 설정 없이 정적 사이트로 배포합니다. `index.html`과 `professor.jpg`를 같은 폴더에 두면 됩니다. 브라우저 저장 데이터는 주소별로 따로 보관되므로 새 주소에서는 빈 상태로 시작합니다.

## 관리자 화면에서 고친 내용

관리자 화면의 저장은 **그 브라우저에만** 적용됩니다. 모두에게 보이게 하려면 **설정 파일** 탭에서 배포용 `index.html`을 내려받아 저장소의 파일을 바꿔 주세요. 브라우저에 저장한 설정은 파일 내용보다 우선하므로, 새 파일을 올렸는데 예전 내용이 보이면 **저장한 설정 지우기**를 누릅니다.

## 보안과 개인정보

- 사이트 전체가 브라우저에서 실행되므로 관리자 비밀번호와 수강생 로그인은 진짜 접근 통제가 아닙니다. 비밀번호 해시도 파일에 공개됩니다. 관리자 비밀번호는 길고 무작위로 정해 주세요.
- 이 저장소의 파일과 커밋 기록은 공개됩니다. 비밀번호와 API 키를 올리지 마세요.
- 내려받은 CSV에는 학번, 휴대폰 번호 등 개인정보가 들어 있으니 안전하게 보관해 주세요.

## 외부 서비스

- **PeerJS 공용 서버:** 실시간 퀴즈의 연결 중개 (사용 보장 없음)
- **jsDelivr, cdnjs:** 퀴즈와 첨부 파일 읽기용 라이브러리 내려받기
- **Anthropic API, BAZE API Gateway:** AI 자료 생성 (키를 등록한 경우에만, 이미지는 BAZE)
- **YouTube:** 관리자가 주소를 넣은 영상과 노래 재생
